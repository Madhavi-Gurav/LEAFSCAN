🌿 LeafScan
AI Assistant for Farmers | Plant Disease Detection using Deep Learning

LeafScan is an AI-powered web application that helps farmers detect plant diseases from leaf images and receive instant, reliable guidance using deep learning and an AI chatbot.

🔍 What Problem Does LeafScan Solve?

Farmers often rely on:
Manual crop inspection,
Delayed expert advice,
Guesswork in disease treatment,

This leads to:
❌ Misdiagnosis
❌ Late action
❌ Crop loss

LeafScan solves this using AI.

💡 What LeafScan Does

🖼️ Upload a plant leaf image
🧠 AI analyzes it using a CNN model
📊 Shows disease name + confidence score
💬 AI chatbot helps with crop-related questions
🌱 Supports better and faster farming decisions

✨ Key Features

🌿 Plant disease detection using CNN

📸 Image-based diagnosis

📊 Confidence score for predictions

💬 AI-powered Farmer Assistant chatbot

🌐 Simple and farmer-friendly web interface

⚡ Fast and automated analysis

🧠 How It Works (Simple Flow)
Farmer uploads leaf image
        ↓
 Image preprocessing
        ↓
 CNN Deep Learning Model
        ↓
 Disease prediction
        ↓
 Result + AI assistance
